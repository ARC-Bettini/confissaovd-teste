# Recomeço — versão de teste

Aplicativo de exame de consciência da Paróquia Verbo Divino, preparado para avaliação.

Esta branch contém somente os arquivos estáticos da versão de teste. A página é autocontida: perguntas, fontes e assinatura oficial estão incorporadas. As licenças das fontes estão em licenses/.

As respostas e anotações permanecem na memória da aba; não são enviadas ao servidor. A aplicação não substitui a confissão sacramental com um sacerdote.

## GitHub Pages

Para usar esta branch como origem, configure Settings → Pages → Deploy from a branch → recomeco-mobile-preview → / (root). A disponibilidade depende das permissões e do plano do repositório. Nenhum endereço deve ser tratado como ativo antes de verificar a publicação.
